# Dashboard Guide — Project Management Power BI

## Report scope

The project analyses a portfolio of 99 projects with reported total project income of 8.83M. The stated reporting areas are project progress, financial performance, expenditure, team contributions, budget information, year-wise trends, regional comparisons, and department-level performance.

## Business areas included

- Warehouse
- Supply Chain
- Sales & Marketing

## Suggested report navigation

The following is a documentation-level guide to the reported analysis areas. It is not a claim about exact page names or visual layouts in the original PBIX file.

| Analysis area | Questions to explore |
|---|---|
| Project overview | How many projects are tracked and what is their completion status? |
| Financial performance | What income and expenditure are reported? |
| Cost trends | How do costs vary across years and regions? |
| Department performance | How do the three stated departments compare? |
| Team and manager contributions | How are contributions represented in the report? |
| Budget tracking | How does reported spending compare with budget information? |
