# Project Management Dashboard — Power BI

An interactive Power BI reporting project built to analyse project progress, financial performance, costs, and department-level performance across a portfolio of 99 projects.

**Technology focus:** Microsoft Power BI · Microsoft Excel · Power Query · KPI Reporting · Data Transformation · Financial Analysis · Project Performance

## Project overview

This dashboard brings project and financial information into a consolidated reporting view. It was designed to help users monitor project completion, income, expenditure, regional trends, and department performance.

The analysis covers **99 projects** and a reported total project income of **8.83M**. The dashboard includes project progress, financial and team-related views, with analysis across Warehouse, Supply Chain, and Sales & Marketing.

## Business questions addressed

- How many projects are included in the portfolio?
- What is the overall project income?
- How are projects progressing toward completion?
- How do costs and financial trends vary across years and regions?
- How do Warehouse, Supply Chain, and Sales & Marketing compare?
- How can managers review project, team, and budget performance in one place?

## Key dashboard capabilities

- **Project portfolio tracking:** review the 99-project portfolio and project completion status.
- **Financial analysis:** examine reported project income, expenditure, and cost trends.
- **Time-based analysis:** compare financial performance across years.
- **Regional analysis:** review project costs and performance across regions.
- **Department analysis:** compare Warehouse, Supply Chain, and Sales & Marketing.
- **Management reporting:** present project progress, financial performance, team contributions, and budget information in interactive report views.
- **Data preparation:** use Power Query to transform and prepare source data for reporting.

## Project workflow

1. Review the project and financial source data in Excel.
2. Prepare and transform the data using Power Query.
3. Build report views for project progress and completion.
4. Analyse income, costs, and financial trends across years and regions.
5. Compare performance across departments.
6. Present the results through interactive Power BI dashboards.
